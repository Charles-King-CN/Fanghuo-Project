# 贵州邮政智慧消防项目关键信息速览

## 1. 关键点

*   **项目范围明确：** 平台建设（消防物联、消防安全管理、消防技术服务）、功能模块（21个）、硬件部署（服务器、前端设备）、实施范围（全省邮政单位及网点）。
*   **分阶段实施：** 先建省级平台，再按市州逐个建设，总周期较长。
*   **软硬件结合：** 平台开发与前端设备部署、集成并行。
*   **与现有系统对接：** 需与“中国邮政安保信息系统”实现信息共享。
*   **运维重要性：** 需建立完善的日常监控、故障处理、系统优化、安全管理和定期维护机制。

## 2. 风险点

*   **需求变更风险：** 项目涉及多层级、多网点，需求可能频繁变化，需严格控制。
*   **范围蔓延风险：** BIM三维可视化和视频智能分析模块的实施范围存在歧义，可能导致范围蔓延。（**试点贵阳、遵义**）
*   **前端设备数量与预算差异风险：** 前端设备据实结算，可能导致最终数量和价格与估算不符。
*   **兼容性风险：** 消防主机增配板卡需求及与现有系统对接可能存在兼容性问题。
*   **网络环境风险：** 各级单位网络环境可能不满足视频联动和实时监控的带宽要求。（**带宽要求，单个1080p-4Mbps，拉新线需要提前申请、审批，做好记录分配**）
*   **验收标准模糊风险：** 初验与终验的具体标准描述概括，可能导致验收争议。
*   **运行期间顺延风险：** 若因我方原因导致运行期间顺延，甲方有权单方面解除合同。
*   **知识产权归属风险：** 可交付物著作权归属及软件著作权授权使用期限需明确，避免法律纠纷。
*   **资金结算风险：** 五年期结算方式及工程费用估算与实际结算的差异，需明确细则。

## 3. 需要与甲方确认的信息

### 3.1 项目范围与需求细节

*   **BIM三维可视化和视频智能分析模块的最终实施范围和功能需求。**
*   **是否有其他已有软件平台需要对接，以及对接费用承担方式。**
*   **前端设备（如热成像火灾探测器、声光警报器、手动报警按钮、Lora烟感、营业网点报警主机接入）的最终数量、规格、部署原则和结算机制。**
*   **现有消防主机的具体型号、数量及是否确实无需额外板卡即可直接对接。**

### 3.2 验收标准与流程

*   **各项功能和性能指标的详细、量化验收标准。**
*   **是否有委托第三方检测机构进行终验的计划，以及其资质要求和检测范围。**
*   **运行期间的起始、结束时间，以及导致运行期间顺延的具体情况和判定标准。**

### 3.3 知识产权与保密条款

*   **明确哪些可交付物著作权归甲方，哪些归乙方但授权甲方使用，并详细列出。**
*   **软件著作权的授权使用期限。**
*   **保密信息的具体范围和明确期限，特别是“与对方有竞争性的业务”的界定。**

### 3.4 培训计划

*   **具体的培训计划附件内容，包括培训对象、内容、方式、时间和地点。**

### 3.5 资金结算与付款节点

*   **五年期结算方式中，每个付款节点的具体金额、付款条件和付款时间。**
*   **工程费用最终结算是否严格按照实际发生的人工日和差旅费用进行，以及核算和确认方式。**

## 4. 甲方需提供的支持

*   **资源提供：** 提供符合配置要求的云服务器资源、必要的网络环境和安全策略、设备安装所需的场地、电源、网络接口等基础设施。
*   **人员配合：** 指定专人负责项目对接、需求确认、现场协调、验收测试和后期运维配合。
*   **技术支持：** 提供“中国邮政安保信息系统”的接口文档、测试环境和技术支持，并协调相关部门进行对接测试和数据验证。
*   **业务配合：** 提供业务需求、参与功能评审、进行用户验收测试（UAT），并提供必要的业务数据和资料。
*   **培训组织：** 积极组织各级单位用户参与培训，并协助推广平台的使用。
*   **合同履行：** 按照合同约定，及时进行阶段性验收和最终验收，并完成项目结算。
*   **安全保障：** 协助确保施工现场的安全生产，提供必要的安全保障措施。
